# SSAO 与音符渲染优化

2026-11-14，用户在性能审查后要求优化 SSAO、SkyArea 和逐 Renderer 属性块。

SSAO 保留效果与现有双边滤波，改为半分辨率计算。SkyArea 保留 5 ms 采样、每连续链单 mesh、共边与 UV 语义；缓存固定的边线和时间映射，单调段用二分裁去只会退化到轨道边界的行，反向/非单调段保留完整行检查。只删除零面积边界面片，不缩短音符可见时间窗。谱面字段、时间轴版本、流速或轨道长度变化均使缓存失效。

每个音符 Renderer 持有独立属性块，首次保留原属性，缓存材质支持的属性；后续只写变化项与变化的 Renderer。对象复用、颜色/方向变化和材质替换须刷新状态。暂停或停走时没有几何变化则跳过天空网格上传。

验证采用原实现作为基线：比较所有非退化面片的顶点和五组 UV、边界与 seek/编辑失效、属性块结果和池复用；测试实际 Unity 场景及官方谱面。运行编译、自检、本地化门，记录热路径 CPU 耗时和上传次数。SSAO 单独做实际画面对比，性能数字不冒充完整玩家 FPS。

2026-11-15 验证完成：专项自检通过；41 组原实现对照验证通过，含真实 HOLD 进行中状态、两种 Flick 颜色、停止/恢复、反向、编辑、池回收和重新 seek，以及 Alamode/Cryogenic/Tokonagi 的难度 3。非退化天空面片顶点与五组 UV 精确一致。纯 TAP 路径保留原有整音符快速跳过，避免缓存层引入稳定帧的额外原生查询。

Unity 编辑器 CPU 微基准中，合成 30 秒天空区从 6001 面片降到 134，音符更新从约 4.876 ms 降到 0.083 ms；三张官方谱面的同一测试位置分别为 0.287→0.082、0.064→0.045、0.129→0.102 ms。这些是 NoteRenderer.Update 的小范围测试，不包含完整 CPU/GPU 帧，也不代表玩家能达到的 FPS。

实际 URP 运行画面保存了普通天空区与连续链接缝的全/半 SSAO 对照。轮廓、接缝、纹理与透明度无明显变化；画面含动画辉光，未把截图宣称为逐像素相同。报告、截图与复现探针在 `Diagnostics/NoteOptimization/`。专项检查接入完整 `FalsumSelfCheck`。本轮没有重新打包 Windows 程序。
