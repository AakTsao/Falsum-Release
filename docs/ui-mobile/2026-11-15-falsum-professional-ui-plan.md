# FALSUM UI 专业化实施计划

依据已获用户确认的 `../specs/2026-11-15-falsum-professional-ui-design.md`。回退入口由用户明确要求。设计效果稿在 `Diagnostics/UiProfessional/Design/`，仅用于界面比例参考，不是运行截图。

1. 保留接手快照，追加 InFalsus 枚举，恢复风格入口，补齐风格名称本地化。新样式使用独立 USS 与 root class，切回 Classic 移除附加样式和 class。手机挂载后重新应用所选风格。
2. 修正现行 Experimental 组的偏好读取，添加主动选择标记；新配置与历史强制 Classic 默认升级到 InFalsus，主动 Classic、Studio、Canvas 和 InFalsus 均能保存并重启恢复，未知枚举回落 Classic。不变更当前偏好版本号。
3. 用新样式统一顶栏、传输栏、属性、事件、偏好、新建、确认、声明、背景、音频预处理、工具、报告与 Bank。英文数字使用既有 Exo，中文保留打包字体。新样式不增加过渡动画，保留播放期间关闭动画的现有优化。
4. 手机样式覆盖具有更高 specificity 的独立规则，保留控件尺度与所有手势，只降低边框、粗体和实底的视觉重量；检查短屏、最大尺度、八行属性和长数字。
5. 更新与风格门有关的既有自检，补充实际磁盘往返和取消预览恢复的验证。运行编译、本地化审计、编辑器与移动 UI 自检。
6. 在独立验证目录生成当前 UITK 截图，覆盖桌面主要面板和手机六组视口。检查实际字体、对比、遮挡和回退；必要时迭代。保留本轮日志、截图和变化清单，不构建或覆盖发布目录。

共享文件每次写入前核对当前内容，不替换整份既有修改；不触碰 NoteRenderer、性能窗口、渲染器、画质设置及其它性能工作。
