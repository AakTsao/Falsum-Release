# FALSUM 制谱器移动端 UI 优化设计

日期：2026-11-12

## 范围与现状

本轮只涉及 FALSUM 制谱器的移动端界面。现有 `FalsumMobileShell` 以横屏双侧工具轨、浮动操作面板、竖向进度条及共用 UXML 事件为基础；`FalsumMobile.uss` 只在移动样式类下挂载，桌面视图保持原状。移动自检目前通过，但现有截图分辨率偏离设计比例，且壳层的安全区与浮层几何主要在挂载/缩放时计算，屏幕尺寸变化时未见持续重排。

## 目标

- 在支持的横屏手机尺寸下保留最大谱面画布，浮层、属性卡和轨道不发生碰撞或出界。
- 旋转、窗口/分辨率变化及安全区变化后重新布局。
- 让高频按钮有稳定触控目标，低频面板可滚动/收起，避免操作挤占谱面。
- 共用现有 UXML 与 View 事件，不复制编辑器/谱面数据逻辑；桌面布局不变。
- 新增文案遵循 FalsumLocalization；所有交互行为沿用现有编辑器事件和撤销事务。

## 方案

沿用现有双轨手机壳，集中增强 `FalsumMobileShell` 的视口适配：监听根元素几何变化，重新计算安全区、两侧轨道、属性面板可用宽度及浮层锚点；按可用画布宽度调整右侧浮层列宽，窄屏时将低优先级信息折叠/滚动，避免通过固定最小宽度制造重叠。屏幕安全边距在首次挂载与后续几何变化时统一应用。

对 UXML/USS 做移动端触控审查：维持手指可点击尺寸与清楚的按下/锁存状态；浮动面板限制最大尺寸并允许内部滚动；属性、事件、工具菜单保持明确关闭路径。只对已发现的移动端遮挡/裁切进行小范围修正，不改变谱面画布手势及既有操作语义。

保持桌面 CSS/事件结构不变；增加移动布局几何自检，覆盖设计 19:9 与较窄横屏下的两侧栏、可用画布和浮层边界。使用现有移动截图工具复核完整编辑器和移动菜单。

## 验收标准

- 在 19:9 设计尺寸及较窄横屏尺寸下，控件不越过安全区，浮层与两侧栏不相互覆盖，中心画布保留可操作宽度。
- 改变可用视口尺寸后，安全区与浮层锚点随之更新。
- 属性面板、事件抽屉和移动菜单内容可完整访问并有返回/关闭操作。
- 移动自检、UI 资源自检、编译与本地化审计通过；桌面切换往返维持现有自检行为。

## 边界

本轮不改变 Android/iOS 构建目标、输入手势、谱面数据模型、游玩 HUD 或编辑器功能集合。项目尚无完整移动平台发布链，本轮验证以编辑器移动布局强制开关、运行时自检和截图为准。
