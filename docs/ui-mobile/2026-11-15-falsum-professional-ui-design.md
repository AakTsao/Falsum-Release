# FALSUM 桌面与移动端 UI 专业化

日期：2026-11-15。用户要求全面改善移动与 PC 界面，参考 `D:/AakTsao WorkSpace/In Falsus Demo` 原版，降低模板化观感，并保留原 UI 回退入口。另一个会话正在验证渲染性能优化。

## 推荐方案与取舍

推荐新增独立的 `InFalsus` 风格：沿用原版深色面板、灰白文字、浅青选中态、细线和角标，并按制谱工具的信息密度重新组织控件视觉。PC 保留菜单与底部传输栏；手机保留单列侧栏与浮窗。旧版 `Classic` 样式完整保留。

另外两种选择是直接模仿游戏的大按钮与装饰面板，或仅调整现有字体和边框。前者会挤占编辑画布，后者无法解决目前过多粗体、蓝色实底和重复分组装饰的问题。

## 原版证据

只读检查原版 `if-app_Data/StreamingAssets/aa/StandaloneWindows64` 中 515 个较小资源包，定位 228 项与 UI 有关的纹理。目录、对象编号与尺寸记录在 `Diagnostics/UiProfessional/Reference/original-ui-assets.json`；抽取的按钮、顶栏、面板、复选框、进度背景和角标见同目录 `original-ui-contact-sheet.png`。

原版 `button-basic` 为深灰面、浅灰细描边；`checkbox-checked` 和 hover 纹理使用浅青白；`btn-square200-right-brackets`、`button-close-brackets` 与 `panel-edgeeffects` 使用细角标。游戏使用部分切角按钮，但编辑器遵守项目直角控件约定。新界面借鉴这套比例和状态语言，不以普通蓝色按钮铺满画面。

## 视觉与信息层级

- 基础色：接近黑的蓝灰画布、深灰面板、灰白主文字、灰色标签；浅青只用于当前工具、焦点、播放与进度。删除沿用克制的红色。
- 全部矩形直角，边框以 1 px 为主。常用工具采用低对比背景，当前工具用细边与浅青文字提示；主确认动作使用浅青浅底与深色文字。
- 中文沿用工程内 Noto Sans SC；英文与数值使用现有 Exo 资源。正文取消普遍的加粗，标题、数值、标签和辅助信息形成明确等级。歌曲卡受保护字体保持原方案。
- 不新增介绍性口号、解释卡或装饰性指标。重复标题和说明只在新风格中隐藏，安全提示、错误信息、快捷键提示与功能名称继续显示。
- 所有新文字使用本地化键，中英同时提供。原版文字及样式资源保留，避免回退时得到混合界面。

## PC

顶栏使用紧凑的菜单与薄分隔线，数值编辑区域保持对齐；底部传输栏把历史、时间与细分、播放进度、辅助操作分为清晰的连续区域。避免每个菜单和字段都像独立卡片。

属性面板采用紧凑的键值表，标签低对比、数值清晰、字段只在悬停和焦点时增强边框。事件列表按表格处理时间和参数，筛选与操作按钮降低视觉重量。乐曲卡保持原版比例和既有编辑热点。

偏好设置、新建谱面、确认与声明、音频预处理、背景选择、工具管理与工具报告、SkyArea Bank 共用一致的标题、内容、页脚与主次按钮。保留足够的滚动空间、错误提示区域和关闭入口。

## 手机横屏

保留当前移动端工作成果：左栏工具与左下多选、右栏操作、浮动流速框、歌曲卡与时间播放浮窗、独立的纵向进度触控区、八行属性、数字键盘和网格长按 2/3/4/6/8。

新风格只改变上述结构的字体、面色、边框、状态和视觉间距；用细角标和低对比描边削弱满屏大方块感。视觉标记可以变小，但既有触控区域不缩小。纵向进度保留当前实际轨道边界与指针转换，不重新实现手势。

手机弹窗使用适合短屏的紧凑标题与字段行，底部操作保持可见。遮罩与数字键盘的层级保持现有规则。覆盖 855×405、640×360、740×320、512×320 和最大控件比例，中英都检查。

## 回退与持久化

恢复 `偏好设置 → 高级 → UI 风格`。选择项包含 `In Falsus`、`旧版 UI / Classic`，并保留既有 Studio、Canvas。新枚举追加在末尾，不改变旧数值。

新配置以 In Falsus 为默认。旧配置中被隐藏入口强制成 Classic、尚未做过新版本选择的配置首次升级为 In Falsus；用独立的选择标记区分这种历史默认值与用户主动回退。用户显式选择 Classic 后，下次打开仍使用 Classic。历史 Studio、Canvas 选择保留。未知枚举安全回落 Classic。预览、取消恢复和完成保存沿用现有偏好设置流程，不为新增字段提高偏好版本号。

当前 `FalsumPreferencesMigration.Build` 不读取现行 `Experimental` 组，只从旧 `Advanced` 组提取 UIStyle；必须恢复该组的读取，否则新风格与主动回退都无法经过真正的磁盘读取。验证同时覆盖保存、重置缓存、重新读取，而不是只做 `JsonUtility` 克隆。

新风格单独使用 `FalsumInFalsus.uss` 与 root class。风格切换移除上一张附加样式表，切回 Classic 不附加新表、不残留新风格字体或 class；动态手机样式挂载后仍正确应用选定风格。不重建编辑器，不改变谱面、世界颜色或背景。

## 并行工作边界

UI 改动限定在风格分发、风格偏好入口与迁移、必要的显示门面、新 USS、对应本地化、UI 自检和本轮文档。修改任何既有文件前保存该文件的当前快照并检查是否被另一个会话更新，保留接手前修改。`FalsumEditor.uss` 已有播放中关闭过渡的性能改动，本轮保留。

不修改 NoteRenderer、SkyAreaRowCache、属性状态缓存、表现时钟、轨道与小节线网格、性能窗口、渲染器和工程画质设置。不覆盖另一个会话的日志，不运行会改写发布资源的构建，不清理工作区。

## 验收

先进行 Unity 编译，再运行现有编辑器自检、本地化审计和移动 UI 自检。自检中原先强制隐藏风格入口的断言同步为当前产品要求，新增切换无残留、有效风格往返、未知风格回退及取消恢复的真实检查。

实际 UITK 截图覆盖 PC 主界面、属性、事件、设置和主要弹窗；手机覆盖上述分辨率、长数字和分数、八行 SkyArea 属性、菜单、设置、键盘及网格长按状态。逐张检查文字裁切、对齐、主次状态和画布占用。

Unity 批处理或截图前检查当前工程锁。若主工程被占用，使用独立验证目录、独立产品名和偏好目录；截图脚本与日志存入 `Diagnostics/UiProfessional/`。验证完成后报告实际通过项与局限，不将布局检查表述为 Android 真机验证。
