# FALSUM 移动端 UI 精修

2026-11-14，按本轮用户给出的布局和交互要求实施。

沿用 Unity UI Toolkit、现有 View 事件和本地化；只调整移动端样式与壳层。直角深色面板，青色用于播放、进度和网格选择状态。保持既有工作区改动。

- 属性框隐藏完整标题容器，行高 22、数字 11、标签 9；减小内边距，按八行 SkyArea 属性加定位按钮计算完整高度。仅极短窗口保留滚动兜底。
- 乐曲卡片最大宽从 176 调到 208，保持 3013:559 比例。下方改成有细边框的单行播放浮窗，仅显示时间框和播放键；隐藏原元数据行，试听入口仍可经菜单和快捷键使用。
- 进度条保留 22 单位触控区，以 2 单位轨道、青色进度填充和带刻痕的小方形手柄显示。拖动时显示时间，放手隐藏；上下端点与指针换算共用实际轨道边界。
- 网格短按切换显示。按住 350 ms 向左展开 2、3、4、6、8，滑动高亮，松手只提交一次；松在外侧、取消或丢失捕获时收起，不提交。按钮显示当前细分值。
- 设置 → 编辑 → 网格增加时间细分；与移动端长按、桌面时间细分共享持久化值。旧配置恢复默认 4，非法输入阻止完成。偏好版本升到 10，不改谱面内容或 BPM 拍号。
- 左侧删除段落选择，多选固定在左下角，放置工具独立滚动。右侧段落选择继续保留。
- 流速滑条在面板纵向居中，轨道填充、手柄和数值采用统一样式。

验证：项目现有离线双程序集编译门、本地化审计、编辑器/移动端自检；在独立验证环境运行实际 Unity 截图，检查 19:9、16:9、短屏及最大控件比例，覆盖八行属性、分数显示、进度和网格手势。避免争抢当前 Unity 工程锁或改动当前场景。

验证已完成：Unity 批处理编译通过；编辑器自检 37 项、移动端壳层自检、UI 回归 8 项全部通过；855×405（中/英）、640×360（默认/最大工具栏比例）、740×320、512×320 六组实际 UITK 布局共 60 项检查通过。长按选择按完整指针事件验证，覆盖短按、滑动时不提交、松手只提交一次、移出取消、PointerCancel 和卸载清理。保存 48 张截图。没有进行 Android 真机测试。
