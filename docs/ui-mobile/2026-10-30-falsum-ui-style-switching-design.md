# Falsum 编辑器 UI 风格与切换设计

## 目标

在保留经典界面的基础上，为 Falsum 编辑器提供两套面向专业谱面创作的视觉风格。减少当前界面中重复的说明性文字，统一参数、按钮、面板和交互状态的视觉语言。

## 已确认的范围

- 保留 `Classic`，沿用现有 UXML、布局、样式与功能。
- 新增 `Studio`（方案 A）与 `Canvas`（方案 B）。
- 两种新风格沿用原版结构，不重新安排工具栏、属性面板、事件面板、歌曲信息和播放控制的位置。
- 在 `首选项 > 高级 > 实验性设置` 中添加 `UIStyle` 下拉选择。
- 不增加新的编辑器工作流，不改变谱面数据、快捷键和编辑行为。

## 视觉方向

### Studio

石墨灰的中性工作区，青绿色只用于焦点、选中、播放及关键操作。减少面板装饰，强化细分隔线、参数对齐和控件状态。采用紧凑的工具栏与等宽数字，形成偏 DAW 的工具感。

### Canvas

深炭色工作区，暖金用于当前状态和主要操作，灰白用于正文。弱化非活动面板与边框，使谱面物件保持最高的视觉优先级。保持经典布局，但降低常驻说明文字的视觉权重。

### 共同规则

- 直角控件，不使用渐变、光晕、胶囊标签或装饰性卡片。
- 沿用现有 CJK 字体资源；改善数字与参数的排版，不依赖网络字体。
- 保留所有可见状态、禁用状态、键盘焦点、选中状态和危险操作区分。
- 新风格隐藏可由控件名称直接理解的重复说明。复杂操作的必要说明保留在提示、状态区或对话框中，不删除错误与警告。
- 谱面世界、物件颜色、背景和实际游戏内容不随 UI 风格换色。

## 技术设计

### 偏好模型

在高级偏好中添加可序列化的 `UIStyle` 枚举，取值为 `Classic`、`Studio`、`Canvas`。将偏好版本升级；缺失或无法识别的值归一化为 `Classic`，确保旧配置可继续使用。

### 样式资源

新增独立的 `FalsumStudio.uss` 与 `FalsumCanvas.uss`，在基础 `FalsumEditor.uss` 与 `FalsumTools.uss` 之后加载。新样式通过 `FalsumRoot` 后代选择器覆盖共享变量、排版、间距与组件状态。

经典风格不加载附加样式表。原有 UXML 元素名称和经典 USS 保持兼容，工具对话框与首选项共用同一风格。样式切换使用一个集中管理的应用入口，避免各窗口分别维护主题状态。

### 切换与事务

首选项继续沿用现有草稿模型：在 `UIStyle` 下拉框中选择后立即预览，点击完成后随其他全局偏好保存；取消、关闭首选项或保存失败时恢复进入首选项前的风格。恢复默认设置会将草稿中的 UIStyle 设为 `Classic`。

切换仅更新界面样式，不重建编辑器、谱面会话或播放状态。外部加载偏好时统一应用一次风格，启动时使用已保存值。

### 文案

新增风格名称与设置分组的中英文本地化 Key。对于 Studio 与 Canvas，通过样式隐藏页面副标题和不必要的逐行描述；不删除控件的可访问名称、工具提示、校验、状态或错误文本。

## 验证

- 偏好默认值、旧配置迁移、非法值回退、克隆与持久化。
- 启动加载、预览、完成保存、取消恢复、恢复默认设置。
- 经典界面不加载新样式；Studio 与 Canvas 切换时无重复样式表。
- 主编辑器、对象属性、事件、菜单、工具对话框、首选项的截图检查。
- 1280x720、1366x768 与 1920x1080 下检查文字截断、控件重叠与滚动区域。
- 执行现有编辑器自检与编译，确保编辑操作和快捷键不受影响。
