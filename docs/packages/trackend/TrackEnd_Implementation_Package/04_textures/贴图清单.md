### 1.1 它长什么样（实测描述）

一张**深色菱形网格**底图，整体亮度很低：

| 实测指标 | 值 |
|---|---|
| 平均亮度 | 50.9 / 255 |
| 亮度范围 | 8 ~ 164 |
| 平均 alpha | 255（**全不透明**，alpha 通道不参与） |

画面内容：

- **主体**：由斜向亮线交织出的规则**菱形网格**（约 10 列 × 10 行），
  线条是淡蓝白色，网格内部偏暗；
- **点缀**：四周散布着若干**灰白色多边形碎片**（类"碎裂玻璃"的大三角面），
  左侧、上方、右侧边缘较明显；
- **中央**：有一道偏暗的竖直带，网格线在此处对比度更低。

> 注意：它不是"中央网格 + 底部三角粒子"那种构图。运行时那 100 个漂浮三角
> 是 **Shader 里现算的**，底图上并没有对应的粒子贴图。

### 1.2 为什么必须是 Mirror

代码里写死：

```csharp
texture.wrapMode = TextureWrapMode.Mirror;   // :415
```

Overlay 用 `uv + (0, 0.5)` 采样底图（`FalsumTrackEndDiamondOverlay.shader:79-83`），
V 会超过 1.0。三种 wrapMode 的实测结果：

| wrapMode | 结果 | 实测依据 |
|---|---|---|
| `Clamp` | 被夹到纹理最上沿，形成**无网格的竖条** | 早期 bug，见 `04-history.md` §16 |
| `Repeat` | V 跨界处出现**横向接缝** | 第 0 行与第 1023 行平均差 **23.53 / 255**（≈9%），直接拼接必有可见断层 ❌ |
| `Mirror` | **跨界无痕** ✅ | 见下 |

**关键点：`Mirror` 之所以无缝，与底图是否对称无关。**
它是把采样坐标**反射**回去（V > 1 时倒着采），边界两侧天然连续；
而 `Repeat` 是把尾部直接接到头部，才需要"首尾像素相等"这个前提——
而这张图首尾相差 23.5/255，不满足。

因此：**不要因为"看起来对称"就换成 Repeat**，也不要把 Mirror 换成 Clamp。
（实测这张图上下镜像差 15.6/255、左右差 10.4/255，本身并**不**严格对称。）

> 这是本项目踩过的坑，见 `docs/memory/04-history.md` §16
> 与 `docs/memory/appendix/detail-rendering.md:57`。

### 1.3 屏幕上的实际可见范围

输出 Quad 的 UV 上限是 `OutputUvMax = 0.5`，Overlay 又偏移 `+0.5`，
所以屏幕上看到的是**源图的下半部分**（V 0.5 → 1.0）：

```text
源图 V 0.0 ────────────────  永远不显示（上半部分）
源图 V 0.5 ────────────────  ← 屏幕顶端
源图 V 1.0 ────────────────  ← 屏幕底端
```

上半部分虽然不显示，但 **不能裁掉**：底图文件和 Shader 的 `+0.5` 偏移是一套
关联设计，删了上半部分会改变采样内容。

### 1.4 想换自己的底图

| 要求 | 说明 |
|---|---|
| **上下边缘必须可无缝拼接** | 这是硬要求：`Repeat` 之所以不能用的实测原因是首尾差 23.5/255。若你换的图首尾严格相等，理论上 Repeat 也行，但**没有理由去改**，保持 Mirror 最安全 |
| 正方形 | 代码的 `fullHeightFraction` 计算与相机 aspect 相关，非方图会变形 |
| 深色 | 平均亮度约 50/255 是本图的实际水平；最终是 `Blend SrcAlpha OneMinusSrcAlpha` 叠在游戏画面上，浅色会过曝 |
| 建议 ≥1024 | 屏幕下半部分会被拉伸到约 40% 屏幕宽 × 23% × aspect 的高度 |
| 全不透明或注意 alpha | 本图 alpha 全 255 但 **Overlay 不用 `_BackingTexture` 的 alpha**（只取 `.rgb`），所以底图 alpha 实际无意义 |

```text
FalsumBackgroundPresenter 所在 GameObject
└─ FalsumTrackEndComposer              (AddComponent 挂在这里)
   ├─ Falsum_TrackEndDiamondMaskResources     (Layer 31, HideAndDontSave)
   │  ├─ Triangles   (MeshRenderer, MaskShader, Layer 31)
   │  └─ Hexagon     (MeshRenderer, MaskShader, Layer 31)
```

Feature 直接 `command.DrawRenderer(...)` 把它们画进 Mask RT。
