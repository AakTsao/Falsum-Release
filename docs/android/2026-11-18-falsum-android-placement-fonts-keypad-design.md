# Android 放置、字体与数字键盘调整

本轮继承“查找免导出 APK 的模拟器测试方案”会话未完成的最后一轮操作。
用户随后补充：在重做按钮右侧加取消按钮，行为与操作时按 ESC 一致。
沿用该会话已说明的交互方案，并保留用户“别构建、别启动 Unity”的要求。

## 放置

仅 Android 的 Flick 与 SkyArea 分离时间选择和横向绘制。

- Flick：点选时间并松手 → 重新按下，拖动位置、宽度与方向 → 松手生成。
- SkyArea：点选头部时间并松手 → 拖动起始边 → 点选尾部时间并松手 → 拖动终止边。
- 横向绘制使用新按下位置作为边界起点，时间来自上一手势锁定的谱面时间。
- 选时间期间移动手指不绘制，不写音符，不创建撤销事务。
- 完成的音符继续复用原来的吸附、边界、方向、时间校验和保存路径。
- 桌面保持原来的放置流程。选择时间后 Android 保留固定时间上的预览。
- 操作提示走两套语言资源；完成一次后提示重新选择时间。

## 字体

- 西文界面沿用用户给的 Bai Jamjuree。
- 中文回退接到 Adobe 官方 Source Han Sans SC Medium；字体数据和 OFL 许可一起打包。
- UI Toolkit 的面板文字设置显式加入思源黑体 FontAsset，编辑器、项目库和
  跨场景加载层共用它；旧 Font 导入器的回退引用仅供旧文字路径使用。
- Combo 使用 Bai Jamjuree SemiBold（600），FontStyle.Normal，保留原字重。
- 场景歌曲信息卡恢复 FalsumSongFont 的保护字体，数字评级恢复 Exo Medium。
- 不删除原有字体资产；字体自检改为检查新的思源黑体资源。

## 数字键盘

- 窗口从 196×184 调到 216×202，按键与字号随之略增。
- 顶部数值栏作为拖动手柄；只捕获该手柄的指针，按键继续输入。
- 记住本次手机壳实例内的浮窗位置，重新打开及屏幕尺寸变化时夹在安全区内。
- 退格使用独立 SVG，避免依赖西文字体不存在的 U+232B 字形。
- 原数字清洗、替换初始值、确认、取消和关闭时序保持不变。

## 取消按钮

- 手机历史栏顺序为撤销、重做、取消，取消使用同款方形按钮与叉号图标。
- 手机壳 → View 事件 → Editor，保持 View 不持有 Editor 的约束。
- 优先关闭浮动数字键盘、菜单或事件窗；编辑取消与键盘 ESC 共用
  CancelEditorInteraction，继续委托 CancelCurrentAction / CancelPastePreview。
- 无项目时安全返回；未完成的放置不增加撤销记录。

## 验证

本轮只运行独立 Roslyn 源码编译（当前 Editor、桌面 Player 和 Android Player
响应文件）、本地化审计、字体内容/引用校验与交互离线检查。
交互检查从当前源码提取真实方法执行，输入、投影、渲染与事务边界用桩替代。
覆盖 Android 时间手势、Flick 双向方向、SkyArea 四步放置、各阶段取消、
负时间、空项目、桌面原流程，以及数字键盘安全区夹取。

Unity 自检、真实 UI 排版和 Android 触摸验证需在用户之后允许启动 Unity 时执行；
离线检查不作为这些运行时验收已经通过的证据。
