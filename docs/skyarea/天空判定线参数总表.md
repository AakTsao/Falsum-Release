# 天空判定线（JUDGEMENT_LINE）参数总表

> 范围：谱面判定线**本体**（那条横线），不是它上面的三角闪烁特效。
> 三角序列特效另见 `SkyJudgementLineEffect`（1448 三角，属性 `a7.shader`）。
>
> 数据源：`GameplaySceneBinding.JudgementLinePath`、场景
> `GameplayRuntime.unity`、`Recovered/Material/judgement-line.mat`、
> `Recovered/9a.shader`。数值逐项取自文件，非估算。

## 2. 材质

判定线本体**不是运行时生成的**，用的是逆向恢复出来的材质资源。

| 材质 | 着色器 | 自定义渲染队列 |
|---|---|---|
| `judgement-line.mat` | `InFalsus/Compat/StenciledUnlitSprite` (`9a.shader`) | **3004** |
| `judgement-below-line.mat` | 同上 (`9a.shader`) | **3005** |
| `judgement_line.mat` | `Universal Render Pipeline/Unlit` | **3001** |
| `judgement_line_alt.mat` | `Universal Render Pipeline/Unlit` | **3000** |
| `matid_judgement_line.mat` | `Universal Render Pipeline/Unlit` | **3006** |

主用材质是 `judgement-line`（queue 3004）与 `judgement-below-line`（queue 3005）：
一对上下配合的线，3005 在 3004 之后绘制。

## 4. 运行时跨材质属性

有一个**共享的世界坐标注入**，判定线位置会推给多个渲染器，让它们按判定线对齐/裁切：

| 属性 | 写入方 |
|---|---|
| `_JudgementLineWorldPosition` | `LaneStateController.cs` / `MeasureLineRenderer.cs` / `FalsumEditorWorld.cs` |

写入前都先 `HasProperty` 检查，缺属性则跳过（不会报错）。

物理位置来源：`master.InverseTransformPoint(binding.JudgementLine.position)`，
在 `MeasureLineRenderer`、`Falsum2DWorld`、`NoteRenderer`、`NoteHitEffectRenderer`
中反复用作 z 基准。

## 6. 与三角序列特效的区别（重要）

这是两个不同的东西，之前容易混淆：

| | 判定线本体 | 三角序列特效 |
|---|---|---|
| 实现 | 场景对象 + 材质 | `SkyJudgementLineEffect` 组件 |
| 着色器 | `9a.shader` (`StenciledUnlitSprite`) | `a7.shader` (`SkyJudgementLineGlow`) |
| 渲染队列 | 3000 / 3001 / 3004 / 3005 / 3006 | **3011** |
| 资源形态 | 静态 `.mat` | 运行时 `new Material` + 1448 三角网格 |
| 构建期依赖 | 材质被场景引用，正常打包 | 需注册 RenderFeature + Always Included Shader |
| 位置关系 | 判定线本体 | 贴在判定线上方（缩放 2.0×0.144，旋转 24.33°） |

三角特效的完整参数见另一份文档（1448 三角、8 行 × 181、Perlin 闪烁等）。

---

## 7. 备注

- `JUDGEMENT_LINE` 的 transform 由场景决定，**代码里没有对它的位置/缩放做运行时改写**；
  各渲染器只读不写（只 `InverseTransformPoint` 取基准）。
- `judgement-line` 与 `judgement-below-line` 是一对：前者画线本体，
  后者画线下方的"地板投影/呼应"，靠相邻的 queue 保证绘制先后。
- 材质里有大量 URP Lit 残留字段（`_BumpScale`、`_Metallic`、`_Smoothness` 等），
  当前 Shader 是 Unlit 变体，这些字段不参与计算，属逆向保留的原始数据。
