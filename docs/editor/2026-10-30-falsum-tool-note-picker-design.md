# FALSUM 外置工具 Note 选择字段设计

状态：已实现，编译与模型验证通过

## 1. 目标

为 FALSUM 外置 JavaScript 工具增加可交互的 Note 选择字段。

工具作者可以在声明式表单中使用 `type: "note"`。用户点击字段旁的“从谱面中选择”
后进入编辑器预览，在 3D 或 2D 视图中点选一个或多个 Note，然后通过右下角
“确定”返回工具并自动填写字段。

首版必须支持：

- 单选与多选。
- 限定可选择的 Note 类型。
- 限定最少、最多选择数量。
- 保留工具表单和 JavaScript 运行时状态。
- 复用现有预览、Note 拾取、选中高亮和时间轴浏览。
- 取消选择时恢复进入选择模式前的编辑器选择。
- 确定后向工具提供稳定的本次执行期 Note key。

## 2. 非目标

- 不增加自由框选、时间区间选择或 Note 列表浏览器。
- 不修改 Note 数据。
- 不允许在选择过程中拖动、删除、创建 Note 或播放。
- 不把 Note 对象转换成可跨工具执行持久化的数据。
- 不支持脚本自定义 Note 高亮样式。

## 3. 表单字段契约

### 3.1 示例

```js
{
  key: "targetNotes",
  type: "note",
  label: ctx.text("form.targetNotes"),
  description: ctx.text("form.targetNotesDescription"),
  required: true,
  multiple: true,
  noteKinds: ["tap", "hold"],
  min: 1,
  max: 8
}
```

### 3.2 属性

| 属性 | 必需 | 默认值 | 约束 |
| --- | --- | --- | --- |
| `key` | 是 | 无 | 遵循现有字段 Key 规则，全表单唯一 |
| `type` | 是 | 无 | 必须为 `"note"` |
| `label` | 是 | 无 | 用于字段标题 |
| `description` | 否 | 空 | 用于字段说明 |
| `required` | 否 | `false` | 参与默认数量约束 |
| `multiple` | 否 | `false` | `true` 时允许选择多个 Note |
| `noteKinds` | 否 | 全部类型 | `tap`、`hold`、`flick`、`skyArea` 的非空子集 |
| `min` | 否 | 必填为 1，否则为 0 | 非负整数 |
| `max` | 否 | 单选取 1；多选不设人工上限 | 正整数，且不得小于 `min` |

规则：

- 除 `type: "note"` 外，其余通用字段规则继续适用。
- `multiple: false` 时 `max` 必须为 1。
- `min` 和 `max` 必须是整数，不接受小数、负数或非有限值。
- `noteKinds` 不得包含未知类型或重复类型。
- 未配置 `noteKinds` 时选择全部四种 Note。
- Note 字段忽略 `step`、`chartPick`、`options`、`mode`、
  `defaultFileName` 和 `extensions`。

### 3.3 脚本数据

无论单选还是多选，`ctx.inputs.<key>` 始终为数组：

```js
[
  {
    key: "note:12",
    id: 12,
    kind: "tap",
    timeMs: 1200
  },
  {
    key: "note:18",
    id: 18,
    kind: "hold",
    timeMs: 1800
  }
]
```

字段：

- `key`：与 `FalsumToolChartSnapshot` 一致的本次执行期 opaque key。
- `id`：工具打开时 Note 的只读 ID 快照。
- `kind`：`tap`、`hold`、`flick` 或 `skyArea`。
- `timeMs`：工具打开时的整数开始时间。

数组按用户在预览中的确认顺序返回；同一 Note 不能重复出现。

## 4. 工具窗口

### 4.1 字段显示

Note 字段在工具表单中使用只读文本框显示选择摘要，并提供
“从谱面中选择”按钮。

摘要规则：

- 未选择时显示空文本。
- 单选显示 Note 类型、ID 和时间。
- 多选显示前若干项摘要；控件无法完整显示时由现有文本省略处理负责。
- 字段下方可显示已选数量及 `min/max` 提示。

完整对象数据保存在字段绑定中，不从显示文本反解析。

### 4.2 进入选择

点击按钮后：

1. 工具窗口隐藏，但工具对话框实例、字段值、JavaScript 运行时和滚动位置保留。
2. 编辑器暂停播放和待提交编辑，进入专用 `ToolNotePick` 模式。
3. 保存编辑器进入前的 Note 选择列表。
4. 根据 `noteKinds` 设置临时拾取遮罩。
5. 已有字段值转换为对应 Note 并显示为初始选择。
6. 显示全屏透明选择层；该层中央不遮挡谱面预览。

### 4.3 Note 选择

- 单选：左键点击可拾取 Note 时替换当前选择。
- 多选：左键点击未选 Note 时加入；点击已选 Note 时移除。
- 相同屏幕位置存在重叠 Note 时，沿用现有重复点击循环逻辑。
- 不可拾取类型的 Note 不响应选择，并沿用现有过滤变暗效果。
- 达到 `max` 后，多选模式不能继续增加 Note；取消已选 Note 始终允许。
- 选择结果使用现有 `_selected` 和世界空间/2D 高亮呈现。

### 4.4 右下角操作栏

选择模式下在预览右下角显示独立操作栏：

- 当前选择数量，例如 `2 / 8`。
- “取消”按钮。
- “确定”按钮。

确定按钮仅在以下条件全部满足时启用：

- 选择数量位于 `min..max` 范围内。
- 所有选择均符合 `noteKinds`。
- 单选模式最多选择一个。

右击或按 `Esc` 等价于取消。

### 4.5 返回工具

确定后：

1. 把当前选择按确认顺序写入待提交字段绑定。
2. 生成 `{ key, id, kind, timeMs }[]` 字段值。
3. 恢复工具窗口和原来的表单滚动位置。
4. 聚焦所选 Note 字段。
5. 恢复编辑器进入选择前的高亮选择。

取消后字段值保持不变，并执行相同的窗口、选择和焦点恢复。

## 5. 编辑器集成

新增内部模式和状态，不改变公开的普通编辑选择行为：

- `EditorMode.ToolNotePick`。
- Note 选择会话及其字段约束。
- 进入前的编辑器选择快照。
- 临时拾取遮罩。
- 选择数量与确认状态。

选择期间：

- 禁用拖动、复制、剪切、删除、粘贴、放置、撤销、重做和播放。
- `Esc` 取消选择，不执行普通编辑器取消动作。
- 滚轮继续按当前网格滚动时间轴。
- 3D/2D 视图切换继续可用。
- 关闭工具、切换歌曲或难度时先安全取消选择会话。

选择层隐藏工具窗口，但保持现有模态层的输入优先级，避免误触顶栏和底栏。

## 6. 字段序列化

`FalsumToolDialogView` 在提交工具表单时：

1. 读取 Note 字段绑定的对象数组，不解析显示文本。
2. 验证数量、类型和重复 Key。
3. 写入 `FalsumToolRunRequest.Values[fieldKey]`。
4. 由现有 `CreateInputValue` 和 JSON 转换流程传入 Jint。

`FalsumToolRuntime` 的编辑 API 不需要新增方法。工具可直接使用：

```js
ctx.inputs.targetNotes.forEach(function (note) {
  ctx.edit.notes.remove(note.key);
});
```

## 7. 错误处理与状态安全

- 无效 Note 字段定义让工具清单或表单加载失败，并显示现有工具错误。
- 选择过程中对应的 Note 被外部操作删除时，确定前重新验证；无效项从选择中移除，
  若数量低于 `min` 则禁止确定。
- 工具窗口关闭、运行时销毁或切换谱面时清理选择会话并恢复编辑器模式。
- 取消、窗口关闭或异常不得改变字段值和谱面数据。
- 选择过程不生成撤销记录。

## 8. 本地化

新增中英文 Key，至少覆盖：

- 从谱面选择 Note。
- 选择模式标题/提示。
- 已选数量与数量范围。
- 取消、确定。
- 类型和数量约束错误。
- 单选/多选选择提示。

所有用户可见文本继续通过 `FalsumLocalization` 和工具语言文件机制获取。

## 9. 测试

### 9.1 表单与模型

- 解析默认单选字段。
- 解析多选字段及全部约束。
- 拒绝未知 Note 类型、重复类型、负数/小数边界和 `max < min`。
- 拒绝单选字段的 `max > 1`。
- 验证字段值始终序列化为数组对象。

### 9.2 交互

- 单选点击替换选择。
- 多选点击加入和移除 Note。
- 重叠 Note 循环选择保持可用。
- 类型限制和数量限制正确阻止非法确认。
- 确定回填字段并返回工具。
- 取消和 `Esc` 保持原字段值并恢复编辑器选择。
- 2D 和 3D 拾取都可用。
- 到达 `max` 后不能继续增加，移除后可以再次增加。

### 9.3 状态安全

- 选择中关闭工具不遗留模式或底层输入状态。
- 选择中切换谱面安全取消。
- 选择过程不改变谱面、撤销或重做历史。
- 已有字段值可重新进入选择并正确预选。

### 9.4 验证命令

- `python Tools/falsum_localization_audit.py`
- Unity 菜单 `InFalsus/Falsum/Run Editor Self Check`
- 对应运行截图和自检 JSON 无新增失败

## 10. 验收标准

- 工具作者可声明单选或多选 Note 字段。
- 用户可以从谱面预览点选符合限制的 Note。
- 多选无需打开额外列表，点击即可增删选择。
- 右下角操作栏可取消或确定，数量不合法时确定不可用。
- 确定后工具字段立即显示选择摘要，脚本收到稳定的对象数组。
- 取消后字段和编辑器原选择均不改变。
- 3D、2D、重叠 Note、单/多选及全部约束通过自检。
