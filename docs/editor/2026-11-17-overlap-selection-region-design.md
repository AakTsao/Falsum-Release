# 重叠音符选择轮替区域

日期：2026-11-17。依据：用户要求在能够同时命中同一组音符的区域内持续轮替。

## 行为与实现

连续点击只要拾取到相同的音符集合，就延续当前轮替。点击坐标无需靠近上一次坐标。
候选集合增减、替换音符或点击空白时重新开始；音符身份按对象引用判断。

首次点击仍使用世界拾取的原有优先级。开始轮替后保留首次命中的顺序，
避免指针移动引起射线深度排序变化，导致跳过或重复选择。
普通选择、Ctrl 多选、工具单音符选择与中键精修共用候选集合判断和保存的顺序。
普通点击仍在松开时切换；拖动仍取消本次切换，保留现有多选拖动与锚点优先级。

## 方案选择

- 扩大固定像素半径：仍会在大型重叠区域内断开，也可能跨越无关区域。
- 按候选集合延续轮替（采用）：范围直接来自现有拾取，符合用户指定的共同命中区域。

## 验证

Unity 编译、完整编辑器自检及现有独立选择自检。
新增选择自检覆盖候选顺序变化、完整轮替回绕、中键保留当前音符、
候选增减、同 ID 不同音符对象、新区域重新开始和清空后的状态。
不调整音符拾取形状、谱面数据或文件格式。

验证结果：Unity 编译退出码 0；完整编辑器自检 43 项通过，包含
`pick_cycle_common_hit_region`；本地化审计通过。
