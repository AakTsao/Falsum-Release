# 设计规则检查

检查当前谱面中的 `TAP` 与 `HOLD` 是否满足基础可玩性规则。

规则：

- 时间使用闭区间，端点相接也算冲突。
- 轨道范围只要相交就报错。
- 检查 `TAP`/`TAP`、`TAP`/`HOLD`、`HOLD`/`HOLD`。
- 宽 Hold 和侧轨 Hold 会检查其完整车道范围。
- 恰好相接的 TAP/HOLD 统一显示为“时间重叠”。
- `FLICK` 不参与 TAP/HOLD 规则。
- `SKYAREA` 不参与重叠判定。
- 首尾相接的 `SKYAREA` 不视为时间重叠。
- 同时出现但没有横向交集，也符合设计规则。

执行后使用报告中的“定位”按钮跳转到问题位置。TAP/HOLD 会同时选中冲突
双方。
本工具不修改谱面，因此不会产生撤销记录。
