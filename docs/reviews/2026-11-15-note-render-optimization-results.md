# 音符渲染优化结果

按用户要求完成 SSAO、SkyArea 和逐 Renderer 属性块优化。

SSAO 保留既有采样与双边滤波，宽高各减半，使 AO 计算纹理的像素数变为原来的四分之一。这个比例只针对 AO 的低分辨率阶段，不等于整体 GPU 耗时缩短 75%。

SkyArea 保留 5 ms 原采样：缓存固定边线、UV 距离和谱面时间映射；单调段二分筛出轨道范围，非单调段继续完整检查。丢弃只会压到判定线/末端的零面积面片。暂停/停走时网格没有变化便跳过上传，但每帧仍更新天空判定线范围，避免辉光状态丢失。时间轴、流速、轨道长度、起止时间、宽度与缓动变化均使缓存失效。分组与重建接线沿用现有逻辑。

音符属性状态由每个 Renderer 独立保存，材质支持的属性只在首次/材质或 Shader 改变后重新检查。后续仅改变化属性，且只有实际有变化的 Renderer 才上传。保留原有整音符稳定帧快速跳过，额外把 Flick 方向/条纹密度放进状态比较。池复用强制重新应用并保留其他属性。该优化减少原生调用和上传，没有宣称已让所有音符进入 SRP Batcher。

## 验证

编译、本地化审计与专项自检通过。专项检查接入完整编辑器自检。

与修改前源码的 41 组实际场景对照检查通过：非退化天空面片的顶点和 5 组 UV 精确一致；HOLD 进行中、颜色/透明度、左右 Flick、同时间编辑、停走/恢复、反向、seek、池回收和复用均覆盖。检查三张官方谱面难度 3 的多个位置。

| NoteRenderer.Update CPU 测试 | 修改前 | 修改后 |
|---|---:|---:|
| 合成 30 秒 SkyArea + 音符 | 4.876 ms | 0.083 ms |
| 160 个稳定 TAP | 0.041 ms | 0.035 ms |
| Alamode 难度 3 | 0.287 ms | 0.082 ms |
| Cryogenic 难度 3 | 0.064 ms | 0.045 ms |
| Tokonagi 难度 3 | 0.129 ms | 0.102 ms |

合成天空区在测试位置从 6001 面片降到 134。微基准在 Unity 6000.3.26f1 编辑器中测量 200 次已经预热的调用，只衡量音符更新，不包含整个 PlayerLoop、渲染线程与 GPU 帧；小数值受到机器调度影响。这些数据不承诺完整玩家 FPS 或 165 Hz 稳定性。

实际 URP 运行截图覆盖普通天空区与连续链接缝，保留了全 SSAO 与半 SSAO 对照。天空区轮廓、接缝和纹理未发现可见变化。动画辉光导致截图有少量变化，因此截图不是逐像素等价的依据；精确等价由几何与 UV 对照检查提供。

产物位于 `Diagnostics/NoteOptimization/`：`Comparison.json`、`Runtime/` 六张截图与像素差统计、两份复现探针和 Unity 日志。源码基线保留在 `Library/RenderOptimizationBaseline/`。产品代码以 `SkyAreaRowCache.cs` 和 `NoteRendererPropertyState.cs` 分别承担缓存与属性状态。

本轮修改在源码中，Windows Player 未重新打包。现有旧包不能用于验证这些改动，下一次构建会使用半分辨率 SSAO 与新的音符热路径。
